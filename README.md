게임 「The Last Express (1997)」 한국어화 패치

버전: 1.0 (2026-XX-XX)
기반: ScummVM 2026.1.0 (커스텀 빌드)

🎮 패치 소개

본 패치는 1997년작 어드벤처 게임 The Last Express의 한국어 번역 패치입니다.

인게임 대사 한국어화

컷신 자막 한국어화

신문, 일기, 문서 등 그래픽 텍스트 한국어화

Korean.HPF 기반 비파괴적 로딩 구조 (원본 폴백 지원)

본 패치는 원작의 의도를 존중하며,
1914년 제1차 세계대전 직전의 공기를 한국어 환경에서도 온전히 경험할 수 있도록 제작되었습니다.

개발/재현 문서는 `Dev_README.md`를 참고하세요.

🧪 지원 환경

ScummVM 2026.1.0 이상

Windows / macOS / Linux / Android

※ Enhanced Edition은 지원하지 않습니다.

📦 설치 방법
방법 A: Windows (권장)

배포 ZIP 압축 해제

Korean.HPF 파일을 게임 데이터 폴더에 복사

커스텀 ScummVM 또는 권장 실행 파일로 실행

방법 B: 기존 ScummVM 사용자

Korean.HPF 파일을 게임 데이터 폴더에 복사

ScummVM에서 The Last Express 실행

Korean.HPF 파일이 존재할 경우 한국어 그래픽 및 자막이 적용됩니다.
파일이 없을 경우 자동으로 원본 영문 리소스를 사용합니다.

🔤 기술 개요

리소스 로딩 우선순위 기반 확장 구조

Korean.HPF 존재 시 한국어 리소스 로딩

미존재 시 원본 폴백

UTF-8 기반 한글 출력 처리

줄바꿈 및 자막 위치 조정
