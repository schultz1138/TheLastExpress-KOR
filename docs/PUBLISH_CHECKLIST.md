- [ ] 원본 게임 아카이브 파일이 커밋되지 않았는지 확인

- [ ] 빌드 결과물(실행 파일, DLL 등)이 커밋되지 않았는지 확인
- [ ] `.gitignore`가 정상적으로 적용되었는지 확인
